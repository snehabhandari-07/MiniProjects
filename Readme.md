# Mini-Projects Repository

A collection of MERN stack and web development mini-projects showcasing various technologies and concepts.

## Projects Overview

### Backend & Node.js Projects

- **[AI-agent/](AI-agent/)** - AI agent implementation with Node.js
- **[LangChain-Agent/](LangChain-Agent/)** - LangChain-based agent for AI workflows
- **[LangChain-Node/](LangChain-Node/)** - Node.js LangChain integration with LCEL chains
- **[Node-Gemini/](Node-Gemini/)** - Google Gemini API integration with Node.js
- **[MyContacts-Backend/](MyContacts-Backend/)** - Backend API for contacts management
- **[URL-shortner/](URL-shortner/)** - URL shortening service

### Full-Stack Projects

- **[Blogging-Application/](Blogging-Application/)** - Complete blogging platform with Node.js backend and views
- **[Online-Voting-System/](Online-Voting-System/)** - Voting system application

### Frontend & CSS Projects

- **[CSS-Mini/](CSS-Mini/)** - CSS mini-projects and exercises
- **[Spotify-CSS-MiniClone/](Spotify-CSS-MiniClone/)** - Spotify UI clone built with CSS
- **[Image-Upload/](Image-Upload/)** - Image upload functionality

## Getting Started

Each project has its own `package.json` and `.env` configuration. To run a project:

```bash
cd <project-folder>
npm install
```

## Environment Variables

Most projects use `.env` files for configuration. Create a `.env` file in each project directory with necessary API keys and configuration.

## Technologies Used

- **Backend**: Node.js, Express.js
- **Frontend**: React, CSS, HTML
- **Database**: MongoDB
- **APIs**: LangChain, Google Gemini, Auth0
- **Tools**: Git, NPM
